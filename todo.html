캘린더 연동

아이폰 달력과 양방향으로 맞춥니다.
아이폰 Safari에서 위 버튼을 누르면 캘린더 구독 창이 뜹니다. 구독 후 설정 → 앱 → 캘린더 → 계정 → 구독 캘린더에서 데이터 가져오기를 15분마다로 두면 자동 갱신됩니다.
구글 캘린더(PC) → 왼쪽에서 캘린더 이름 옆 ⋮ → 설정 및 공유 → 맨 아래 캘린더 통합 → iCal 형식의 비공개 주소를 복사해 붙여넣으세요. 개인·가족 캘린더를 따로 넣고 영역을 지정하면 됩니다.
