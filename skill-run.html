🧩 전체 스킬 3부 실행

투자 스킬 전체를 세 번에 나눠 돌립니다. 회차마다 따로 요청할 수 있고, 아래에 회차별 마지막 실행 결과가 표시됩니다.

작동 방식
  1. 📨 실행 요청 — 요청이 서버 대기열에 쌓이고 @Tistock_bot으로 알림이 갑니다. 같은 회차는 한 번만 대기합니다.
  2. Claude 데스크톱에서 “스킬런 요청 처리해줘”라고 말하면 대기 중인 회차를 순서대로(1→2→3) 실행하고, 끝난 회차는 대기열에서 지웁니다.
  3. 📋 문구 복사 — 대기열 없이 바로 돌리고 싶을 때. 복사된 문구(예: “전체 스킬 2부”)를 Claude 데스크톱 새 대화에 붙여넣으세요.
  4. 회차가 끝나면 이 페이지의 결과 칸과 텔레그램 요약이 갱신됩니다. 3부가 끝나면 종합 보고서가 게시됩니다.
